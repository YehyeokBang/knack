# knack GitHub 소셜 프리뷰 썸네일 — 디자인 스펙

- 날짜: 2026-06-07
- 상태: 디자인 확정 (사용자 승인 완료)
- 산출물: `assets/social-preview.png` (1280×640) + 소스 `assets/social-preview.html`

## 목적

knack 플러그인 홍보용 가로형 썸네일 1종. GitHub repo Settings의 Social preview에
업로드하면 링크 공유 시 (Slack, X, 카카오톡 등) OG 카드로 자동 노출된다.

포지셔닝: **개인 습관의 박제**가 중심, 공개 배포니까 "같이 쓰자" 뉘앙스 살짝.
"knack"이라는 단어 자체(설명하긴 어렵지만 손에 익은 재주)가 메시지다.

## 규격

- 1280×640 px (2:1), PNG
- 축소 노출 검증 기준: 400px 폭 (트위터/슬랙 카드) — 모든 텍스트 줄바꿈 없이 한 줄 유지

## 레이아웃

좌 브랜드 / 우 터미널 실연의 2칼럼 구성.

| 항목 | 값 |
|------|-----|
| 좌우 패딩 | 4.5% |
| 좌측 칼럼 | 36% (flex-basis) |
| 칼럼 간격 | 4% |
| 수직 정렬 | center + 좌측 블록 `translateY(-28px)` (시각 중심 보정) |

## 좌측 — 브랜드 블록

| 요소 | 사양 |
|------|------|
| 워드마크 "Knack" | Caveat 700, 150px, `-webkit-text-stroke: 2px`, -2° 회전, 색 #2b2620 |
| 서브카피 | "말로 하기 어려운<br>나만의 요령들" |
| 서브카피 폰트 | 나눔펜스크립트 (Nanum Pen Script) 60px, `-webkit-text-stroke: 1.4px` (가짜 볼드 — 폰트가 400 단일 웨이트), -1° 회전, line-height 1.45, 색 #2f2922 |
| 영문 태그라인 | 없음 — 한글 단독 (기각: "Skills for the way you already work") |

## 우측 — 터미널 목업

| 요소 | 사양 |
|------|------|
| 컨테이너 | 배경 #161b22, 보더 2px #30363d, 라운드 16px, 그림자 `0 10px 36px rgba(43,38,32,0.22)` |
| 타이틀바 | #21262d, 신호등 점 3개 (20px, #30363d) |
| 폰트 | JetBrains Mono 24px, line-height 1.7 |
| 명령어 색 | #7ee787 (그린) + bold |
| 설명 색 | #9aa4b2 |

터미널 내용 (확정 카피):

```
> /knack:handoff
붙여넣기 한 번, 새 세션에서 하던 작업 그대로

> /knack:retune
이 내용을 PM이 이해하기 쉽게
```

카피 의도:
- handoff — 행동(붙여넣기 1회)을 앞에, 결과(작업 연속)를 뒤에. 파일 저장·직접
  복사 없이 맥락 기반으로 이어간다는 편의성 강조.
- retune — "이 내용을"로 시작해 handoff 줄과 단어 반복 없음.

## 색 — 크림 종이

| 용도 | 값 |
|------|-----|
| 배경 | #f5f0e4 (크림 종이) |
| 잉크 텍스트 | #2b2620 / #2f2922 |

의도: 종이 위 잉크 손글씨(아날로그 요령) ↔ 다크 터미널(디지털 스킬)의 대비로
"수첩의 요령 → 스킬" 제품 서사를 색으로 표현. 다크 썸네일이 많은 소셜 피드에서
차별화 효과도 있다.

## 제작 방식

1. 위 사양대로 standalone HTML 작성 → `assets/social-preview.html`
2. 1280×640 뷰포트로 렌더 후 PNG 스크린샷 → `assets/social-preview.png`
3. 폰트는 Google Fonts (Caveat, Nanum Pen Script, JetBrains Mono) — 렌더 시 로드
4. 400px 축소 가독성 최종 검증 (모든 텍스트 한 줄 유지)
5. GitHub Settings > Social preview에 PNG 업로드 — **수동 단계** (API/git 불가)

`plugins/` 미변경이므로 버전 범프 대상 아님. 작업 브랜치: `feature/social-preview`,
완료 시 main으로 squash merge.

## 기각된 대안

- A안 사전 항목 (knack 컨셉 전면): 제품 증거 없음 → 기각
- B안 터미널 단독: 브랜드(단어의 매력) 죽음 → 기각, 단 터미널 필수 요소로 흡수
- 폰트 C1 세리프 / C3 모노스페이스: C2 손글씨가 "박제" 톤과 직결 → C2 채택
- 개구체 700 (진짜 볼드): 인상이 귀여움 쪽으로 이동 → 나눔펜 + 스트로크 채택
- 모눈 노트 배경: 축소 시 노이즈/모아레 위험 → 무지 크림 채택
- handoff 카피 "재설명 0회" 계열: 맥락 연속·편의성이 핵심이라 교체
